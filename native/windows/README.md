Windows process-loopback helper. Requires Windows build 20348 or newer. It emits 48 kHz stereo signed 16-bit PCM on stdout and diagnostics on stderr. Built with the Windows SDK and MSVC by .github/workflows/build-native-audio.yml. The helper uses the Microsoft ApplicationLoopback API. Window mode includes only a process tree; screen mode excludes the unique Discord process tree and stops if that tree changes. No Electron system-loopback fallback is permitted.
