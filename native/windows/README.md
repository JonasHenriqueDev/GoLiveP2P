Windows process-loopback helper. Microsoft documents build 20348 as the minimum; independent projects report that updated Windows 10 2004+ builds may also work. The app attempts activation on those systems and fails closed if the API rejects it. The helper emits 48 kHz stereo signed 16-bit PCM on stdout and diagnostics on stderr. Built with the Windows SDK and MSVC by .github/workflows/build-native-audio.yml. Window mode includes a process tree but rejects Discord and GoLive descendants. Monitor audio is disabled. No Electron system-loopback fallback is permitted.
